# benfuller.github.io

Personal resume site for Benjamin Fuller, live at <https://benfuller.me>. Plain static files served by GitHub Pages; no framework and no runtime dependencies.

## Editing content

Everything on the site (English and Spanish) is generated from one file:

- `_src/content.py`: roles, projects, skills, press, company pages, UI strings, privacy policy. Every string is `T("English", "Español")`.
- `_src/build.py`: the generator (Python standard library only).
- `style.css`, `site.js`: hand-written front end. `consent.js` is generated from `_src/consent.tmpl.js`.

```sh
python3 _src/build.py          # rebuild every page, the search index and the sitemap
python3 _src/build.py --pdf    # also regenerate the résumé PDFs (needs Google Chrome)
python3 _src/make_og.py        # regenerate the link-preview card media/og-card.png (needs Pillow)
```

Generated files are committed (GitHub Pages serves the repo root), so rebuild before you commit. The résumé PDFs are **not** regenerated by a plain build; run with `--pdf` after changing roles, bullets, skills or the summary.

## Things to set in `_src/content.py`

- `SITE["posthog_key"]`: PostHog project token. Empty means analytics never loads (the consent banner still appears).
- `SITE["contact_email"]`: shown on the privacy page when set; otherwise it points to LinkedIn.
- `SITE["retention"]`: must match the retention configured in the PostHog project.
- `AT`: estimated position of each project on the timeline page (year, month).
